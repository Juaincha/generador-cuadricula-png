# Generador de cuadrícula PNG

Herramienta **gratuita y de código abierto** para crear cuadrículas en PNG directamente en el navegador. Sin registro, sin pagos y sin marcas de agua.

👉 **Úsala aquí:** https://juaincha.github.io/generador-cuadricula-png/

## Qué puedes configurar

- Filas, columnas y tamaño de celda (ancho y alto en píxeles)
- Ancho y color de las líneas
- Estilo: líneas continuas, discontinuas, punteadas, de mira o de puntos
- Espacio entre celdas, relleno alrededor y color de fondo
- Fondo **transparente**

Puedes descargar el resultado como PNG, copiarlo al portapapeles o copiarlo como texto Base64 (data URL).

## Privacidad

Todo funciona en tu navegador. Ninguna imagen se sube a ningún servidor.

## Usos comunes

Pixel art, punto de cruz y bordado, caligrafía, papel cuadriculado para imprimir, guías de diseño, mapas de juegos de mesa y superposiciones para dibujo.

## Usarla sin conexión

Descarga `index.html` y ábrelo en cualquier navegador.
