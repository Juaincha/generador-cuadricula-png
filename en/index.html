How to make a PNG grid

  1. Pick a line style: solid, dashed, dotted, crosses, or a dot grid.
  2. Set the number of columns and rows, the cell size, and the line width.
  3. Choose your colors. Tick Transparent for the cell fill or background to leave them see-through.
  4. Optionally add a gap between cells or padding around the edge.
  5. Click Download PNG, or Copy image to paste it straight into another app.

FAQ

Is it really free?

Yes. No payments, no account, no watermark. The code is open source, so anyone can read it, copy it or improve it.

How do I get a transparent grid PNG?

Leave Transparent ticked for both “Cell fill” and “Background”. The PNG keeps its transparency; the checkerboard in the preview is only there so you can see it and is not part of the image.

Is my image uploaded anywhere?

No. Everything is drawn in your browser and nothing leaves your device.

What can I use it for?

Printable graph paper, pixel art and cross-stitch templates, handwriting and calligraphy practice, layout guides, board game maps, drawing grid overlays, and measurement references.

Is there a size limit?

Yes: 16,000 pixels per side, so your browser doesn’t freeze.

Can I type in a color?

Yes. Besides the color picker, the text field accepts any CSS color: #ff8800, rgb(0 0 0 / 50%), teal…
